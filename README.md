# アンダー100

地上0階から地下100階を目指すブラウザ用コマンドRPG。外部フォント・画像・ライブラリは不要です。

各層の都市で「ダンジョンに進む」「アイテムを買う」「宿泊する」、都市固有の施設を選べます。迷宮で3区画の敵を倒すと最奥のボスに挑めます。ボスを倒すと地下階段が出現し、次の層の都市へ進めます。都市へ戻っても探索状況は維持されます。地下100階への到達で踏破となります。

都市の固有施設は5種類の地区で繰り返します。敵の能力・報酬・薬草の回復量は階層で変化します。

## 遊び方

index.htmlを開くか、https://sakure-trpg.github.io/under100/ にアクセスします。クリックまたは数字キー1〜6で選択できます。戦闘中はセーブできません。記録はブラウザごとに保存されます。旧「星灯りの旅人」のセーブは引き継ぎません。

## 公開・検証

mainへのpushでGitHub Pagesへ自動公開します。Settings → Pages → SourceはGitHub Actionsを選びます。

node --check game.js
node game.test.cjs

## 職業・スキル・装備

6能力値は器用度・俊敏度・筋力・生命力・知力・精神力。通常レベルと装備、職業の育成が能力値に反映されます。基本職は戦士・斥候・魔術師・治療師で、初期は全職Lv.0（非活性）。通常レベルアップごとに経験点3点を獲得します。職業Lv.1/2/3への育成にはそれぞれ1/2/3点を使い、各段階でスキルを1個解放します。都市で最大5個を持ち込み編成し、戦闘中のスキルから選択します。スキル未編成時は戦闘のスキルボタンを利用できません。

頭・上半身・下半身・アクセサリー5枠は都市で支給装備から選択できます。各装備は1個ずつで、同じ物の重複装着はできません。既存セーブは通常レベル・階層を維持し、過去のレベルアップ分の経験点を付与して移行します。

## アップデート時の引き継ぎ
操作ごとに自動保存し、起動・再読み込み時に自動再開します。戦闘中の敵HPも復元します。自動保存がない場合は既存の手動記録から再開します。手動記録は別に残せます。同じブラウザ・同じ公開URLで利用してください。ブラウザのサイトデータを消すと記録も失われます。


## 手の武器・素材
右手と左手に片手武器を1個ずつ、または両枠を使う両手武器を装備できます。武器は都市の支給品から選べます。両手武器の攻撃力は1回分だけ加算します。片手武器への変更で両手武器は外れます。同じ支給武器の重複装備はできません。
敵を倒すと通常35%、ボス70%で素材を1個獲得します。素材は所持素材欄で確認でき、自動保存されます。現段階では素材の収集まで対応しています。


## ボス固有装備
ボスの通常素材70%と固有装備1%は別々に抽選します。石門の番人：石門の兜、深層の騎士：深層騎士の剣（片手）、坑道の巨獣：巨獣の大斧（両手）、影の司祭：影司祭のロザリオ（アクセサリー）。入手した固有装備だけ都市で装備できます。所持数はボス固有装備欄で確認でき、自動保存・旧データ移行に対応しています。


## 難度調整
通常敵HPは38+階層×12、攻撃13+階層×3。ボスHPは100+階層×26、攻撃19+階層×4。敵には物理防御があり、ボスは3回目の反撃ごとに1.8倍の強撃を使用します。直前に予告を表示するので防御で軽減できます。
レベルアップの回復はHP12・MP3に変更。薬草は25+階層×2回復、魔力水は8+階層÷2（切捨て）回復。薬草12G・魔力水25G・宿20+階層×3G。支給武器の攻撃力を抑え、鍛冶費用を引き上げました。救助時は未踏破の探索進捗が0に戻ります。既存セーブの階層や所持品は維持し、変更は新たに遭遇する敵から適用します。


## 片手盾・最新メッセージ
鉄の片手盾は左右どちらの手にも装備でき、防御力が6上がります。片手武器と併用でき、両手武器とは併用できません。階層パネルの直下に最新メッセージ1件を表示し、履歴はコマンド下の冒険の記録に残します。


## 五つの地下世界
世界設定はWORLD.mdを参照。ゲーム内でも階層直下の地域表示とキャラ欄の「世界の構造」で確認できます。21・41・61・81層で次の世界の上空へ抜けます。新たに遭遇する敵・ボス・都市が地域別に切り替わります。
